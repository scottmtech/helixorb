Helixorb drop-in

Public entry is css/orbs.css. These two are the recommended variants — orbit and spiral, shell-first. Markup matches snippets/lattice-orbit.html and snippets/lattice-spiral.html. No build, no CDN, no required JS. MIT licensed.

Copy-paste

<link rel="stylesheet" href="css/orbs.css">

<!-- paste snippets/lattice-orbit.html or snippets/lattice-spiral.html -->

<script>
  const orb = document.querySelector(".orb");
  orb.dataset.state = "listening";
</script>

State API

data-state on the orb: idle · thinking · listening · talking. writing is a talking alias. The buttons above only do orb.dataset.state = '…'.

const orb = document.querySelector(".orb");
orb.dataset.state = "listening";

js/orb.js is optional: Helixorb.setState(orb, "thinking") (MatrixOrb still works).
